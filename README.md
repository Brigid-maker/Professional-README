# Cheryl Adhiambo - Week 03 Project

This project is a multi-page portfolio website designed to showcase my work, skills, and contact information. This week, I focused on building a responsive layout, structuring multiple pages, and learning best practices for accessibility and semantic HTML.  

## Live Demo

[View Live Site](https://Brigid-maker.github.io/iyf-s10-week-01--Brigid-maker.md)

## Features

- ✅ Responsive design that works on mobile and desktop  
- ✅ Accessible (WCAG compliant)  
- ✅ Multi-page layout including About, Projects, and Contact pages  
- ✅ Contact form for users to reach out  

## Technologies Used

- HTML5  
- CSS3 (Flexbox, Grid)  
- Git & GitHub
